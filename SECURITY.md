# Security policy

Please **don't open a public issue** for a security problem. Report it privately through GitHub:

- **Uptimy** (app.upti.my, the API, status pages, alerts, emails): on the [feedback repository's Security tab](https://github.com/uptimy/feedback/security/advisories/new).
- **An open-source project** ([agent](https://github.com/uptimy/agent), [uptimyctl](https://github.com/uptimy/uptimyctl), [mcp](https://github.com/uptimy/mcp)): on that repository's Security tab. Its SECURITY.md says what's in scope.

Include what you found and how to reproduce it, with any API keys or webhook URLs removed. You'll hear back within 3 working days. We'll keep you updated while we fix it, credit you if you'd like, and ask you to hold off on public disclosure until the fix is out.

Please test only against your own workspace and don't access other people's data, degrade the service or send spam.
